## 3. 怎么切 / 怎么验

```bash
python scripts/set_face_lock.py          # 列出三代锁
python scripts/set_face_lock.py --check  # 校验现场图与 default 是否一致
python scripts/set_face_lock.py locked   # 切到 GitHub 新锁
python scripts/set_face_lock.py in_use   # 切回旧锁（现用）
```

- 切换前会**先校验源文件 md5**，对不上直接拒绝；
- 被换下来的那张自动进 `assets/_archive/host_look-<md5前12位>.jpg`，**不删图、可回滚**；
- 切换后会把 `ASSETS-LOCK.json` 的 `default` 改成新值，下次 `--check` 就是自洽的。

实测（2026-11-08）：`in_use → locked → in_use` 来回切两遍，md5 校验全过。

## 5. 硬规矩（别破）

1. **同一张脸**：只在这三代 md5 里选，选完记进 `ASSETS-LOCK.json`，别再造第四张。
2. **左胸小痣（观众右侧）**：凡露锁骨/胸口的半身与七视正视、3/4 —— 必须在。
3. **头大小与胸量**：肉眼对齐 preferred（新锁），不要每批自己重定。
4. **七视下装按 look 走**：00/01 肉色内裤、02 黑铅笔裙、03 牛仔热裤、04 深蓝西装短裤、05 黑缎微裙、06 黑高腰瑜伽裤、07 藕粉整裙。
5. **别二次压缩定妆**：发糊/过压的 JPEG 喂 H3，出来就是蜡脸。上传 GitHub 时尤其别让客户端重编码（本仓新锁 181 KB vs 本机 244 KB，就是被重编码过一版）。

## 6. 和 vivi 现有流程的冲突提醒

- vivi 的 `persona.json` 把服装写死成「白色罗纹背心」：新锁是**短款**背心，提示词里的 `white ribbed tank top` 仍然成立，但**领口更低、露腰**——换锁会改变出画观感。
- vivi 出画档现在是 `576×1024 + turbo 4 步`，属于草稿档；花花硬规要求交付档 `704×1280 + steps≥8`。定妆是 864×1152，别再往下压。
