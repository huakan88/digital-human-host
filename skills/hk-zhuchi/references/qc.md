# 出片自检清单

## A · 口型（最关键）

- [ ] 提示词里有 `<Picture 1>` 和 `<Audio 1>`
- [ ] 台词没写进提示词
- [ ] 提示词要求了 "lips resting closed during pauses"
- [ ] 抽连续 30 帧看嘴部帧条：有「张嘴 → 露齿 → 闭嘴」的变化，不是全程一个样
- [ ] 跑 `python scripts/lipsync_eval.py <段视频.mp4> --plot 对照.png --sheet 帧条.png`，
      看「音频能量」与「嘴部开合」两条曲线峰值是否对得上

```bash
python scripts/lipsync_eval.py cut/s1.mp4 --plot p.png --sheet s.png
```

> 指标只是代理，**以帧条为准**：连续帧里要能看出音节变化。

## B · 画面

- [ ] 开场第 3 秒：数字人**全屏**，有手部/身体动作，脸在画面正中不是大脸
- [ ] 正文第 15 秒：小窗在**左下角**，直径约 200px，白边，不挡字幕、不挡章节条
- [ ] 小窗里的人脸在圆窗内（没被裁掉）
- [ ] 正文素材：与该句口播**一一对应**，没有通用凑数画面，跨段不复用同一素材
- [ ] 16:9 素材竖版化后是「模糊底 + 完整画面」，没有把猫/主体裁掉
- [ ] 每个卡片出现时的帧都抽过，文字没被裁

## C · 文字与包装

- [ ] 章节条：段数与切章一致，章宽按真实时长比例（不是等分）
- [ ] 关键词在稿子里真实存在（`check_edit.py` 会拦）
- [ ] 同一个数字不重复出现两次（`pack` 组件和 `cards` 别都放同一个数）
- [ ] 结尾号召在最后 3 秒出现
- [ ] 左上角有「内容由 AI 数字人演绎」

## D · 声音

- [ ] 旁白是本机克隆音色（huakan），不是云端音色
- [ ] 段间有 0.25 秒左右停顿，不是一路连读
- [ ] 小窗静音，没有叠两遍人声
- [ ] BGM 在人声下（vol 0.075 左右），闭眼只听音轨时每个字都听得清
- [ ] 成片响度 **-16 LUFS / TP -1.5**

```bash
ffmpeg -i out/raw.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:v libx264 -crf 20 成片.mp4
ffprobe -v error -show_entries format=duration,size -of default=nw=1 成片.mp4
```

## E · 事实与合规

- [ ] 每个数字都有出处（论文 / 官网 / 数据库），没有编造
- [ ] 画面里的数字和口播里的数字**同源**（同一篇论文 / 同一个页面）
- [ ] 没有引用 AI 批量生成的假报告站数据（同一细分出现多个互相矛盾的数字 → 弃用）
- [ ] 数字人用的是**本人**形象或明确授权的形象
- [ ] 素材有信源标注

## F · 收尾

- [ ] `ffprobe` 校验时长 / 帧率 / 分辨率
- [ ] 成片留在本地磁盘并给出绝对路径（除非用户点名要网盘）
- [ ] 副产品清掉：`.tmp/`、`tmp/`、中间 `cut/*.mp4`
